# Budborne: First Seed 🌱

The first living prototype of **Budborne**, a world of plant-born creatures, farming, exploration, battling, ownership, and player trade.

This repository begins deliberately small: **one creature worth caring about before an economy worth trading in.**

## First principles

- The game does not sell power. Gameplay produces creatures, abilities, items, land, and rare discoveries.
- Players may own and trade what they earn.
- On-chain systems exist where ownership, scarcity, provenance, and transfer actually benefit from them.
- Fun comes before token mechanics.
- Budborne stands on its own identity.

## First Seed

The GitHub Pages build is Creature Zero: a tiny persistent plant creature. Water it. Give it sunlight. Its local state survives reloads.

No blockchain. No marketplace. No token.

First, we grow something.

> Plant the seed.
